# EFT – Modelamiento de Bases de Datos

Proyecto desarrollado para la Evaluación Final Transversal de la asignatura **PRY2204 – Modelamiento de Bases de Datos**.

**Autor:** Cristofer Medel Sepulveda  
**Carrera:** Analista Programador Computacional

## Descripción

Diseño e implementación de una base de datos para gestionar clubes de fútbol, trabajadores, jugadores, personal de planta, idiomas e historial de permanencia en clubes.

Incluye el Modelo Entidad Relación Extendido (MER-E), el Modelo Relacional normalizado hasta tercera forma normal y su implementación en Oracle.

## Archivos

- **EFT_S9_Cristofer_Medel.docx:** documento de entrega con los modelos.
- **EFT_S9_Cristofer_Medel.sql:** creación de tablas, restricciones, secuencia, triggers, poblamiento y consultas solicitadas.
- **EFT_S9_Cristofer_Medel.zip:** diseño de Data Modeler con el archivo `.dmd` y su carpeta de recursos.

## Herramientas utilizadas

- Oracle SQL Developer.
- Oracle SQL Developer Data Modeler.
- Oracle Database en la nube.
